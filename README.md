# Advanced JavaScript

Course homeworks covering advanced JavaScript concepts including functions, DOM manipulation, prototype-based inheritance, OOP simulation, and design patterns.

## Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 1 | Functions and Function Expressions | Function arguments, `this` context, closures, DOM traversal |
| 2 | DOM Manipulation | Webinar forms, email validation, paragraph/HTML generators |
| 3 | Prototype Chain and Inheritance | 2D geometry structures using pseudo-classical and prototypal models |
| 4 | Simulating OOP | Bug fixes, array flattening, string utility methods |
| 5 | Design Patterns | Module pattern with TODO List application |

## How to Run

1. Clone the repository
2. Open any `index.html` file in a web browser
3. For standalone `.js` files, run with Node.js:
   ```bash
   node <filename>.js
   ```
